# Board Game Night Planner

Board Game Night Planner is a simple full-stack web application for managing board games, friends, and game loans.

I made this project to practice working with databases, Java, Spring Boot, and frontend development.

## What the project does

- Add and manage board games
- Store the minimum and maximum number of players
- Store game complexity
- Add friends
- Keep track of which friend has borrowed a game
- Store borrow and return dates

## Technologies Used

- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Maven

## Database

The project uses MySQL with three main tables:

- Games
- Friends
- LoanLog

## Project Structure

The backend is built using Spring Boot and follows a basic structure with:

- Entity classes
- Repository classes
- Controller classes

The frontend uses HTML, CSS and JavaScript.

## Running the Project

1. Clone the repository.
2. Open the project in VS Code or another Java IDE.
3. Make sure Java and MySQL are installed.
4. Create the required MySQL database.
5. Update the database details in `application.properties`.
6. Run the Spring Boot application.
7. Open the application in a browser.
